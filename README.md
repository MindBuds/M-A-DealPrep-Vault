# 🏆 M&A DealPrep Vault
An advanced, local interview rehearsal sandbox and live case study simulator tailored for aspiring Investment Banking and Private Equity analysts.

## 🚀 Features
* **📊 Interactive Case Studies:** Real-time M&A model adjustments (Premium, Debt/Stock mix, Interest Rates, Synergies) calculating pro forma EPS accretion/dilution and implied valuation multiples instantly.
* **🧠 Technical Q&A Bank:** A curated registry of institutional-grade technical questions spanning accounting link questions, valuation methodologies, and structural M&A accounting rules.
* **🎤 Pitch Rehearsal Studio:** Dynamically engineered verbal scripts configured to match your active financial parameters. Built with complete client-side data privacy to ensure no video/audio data streams leave your machine.

## 🛠️ Tech Stack
* **Frontend/Hosting:** Streamlit
* **Data Processing:** Pandas
* **Visualizations:** Plotly Graph Objects
